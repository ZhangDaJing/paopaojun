📋 首次使用需要创建表：

在 Supabase 控制台 → SQL Editor 中执行以下 SQL：

CREATE TABLE records (
  id BIGSERIAL PRIMARY KEY,
  sector TEXT, operation TEXT, op_type TEXT, op_label TEXT,
  fund_raw TEXT, fund_name TEXT, fund_est NUMERIC,
  amount_raw TEXT, amount NUMERIC, amount_pct TEXT,
  blogger TEXT, month_return TEXT, year_return TEXT,
  holdings_raw TEXT, holdings_num NUMERIC, style TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
